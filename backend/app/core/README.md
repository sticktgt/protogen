# backend/app/core

Тонкое ядро приложения.

Ядро отвечает за:
- авторизацию;
- пользователей;
- выбор и создание workspace;
- чтение конфигураций;
- каталог подключенных модулей;
- выдачу машинно-читаемой документации;
- минимальные системные admin-функции;
- helper-ы для истории через git.

Ядро не является активной платформой для бизнес-логики модулей и не валидирует их внутренние настройки.
