# config

Общая runtime-конфигурация приложения.

Файлы и папки:

- `app.yaml` — общие настройки приложения, путей, UI, сессии и истории;
- `modules.yaml` — список подключенных модулей;
- `users/` — пользователи и их персональные настройки.

Runtime-конфиг конкретного модуля находится в `modules/<module_id>/config.yaml`.
