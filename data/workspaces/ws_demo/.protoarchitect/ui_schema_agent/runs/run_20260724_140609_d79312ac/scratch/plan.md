# План синхронизации UI-схемы

## Анализ входных данных

### Требования (108 требований REQ-0001 — REQ-0108)
- **GRP-AUTH**: Авторизация (REQ-0001–REQ-0007)
- **GRP-NAV**: Навигация и главная страница (REQ-0008–REQ-0018)
- **GRP-PRODUCTS**: Банковские продукты (REQ-0019–REQ-0024)
- **GRP-ACCOUNTS**: Счета (REQ-0025–REQ-0036)
- **GRP-PAYMENTS**: Переводы (REQ-0037–REQ-0047)
- **GRP-DEPOSITS**: Вклады (REQ-0048–REQ-0058)
- **GRP-CREDITS**: Кредиты (REQ-0059–REQ-0067)
- **GRP-CARDS**: Карты (REQ-0068–REQ-0076)
- **GRP-ANALYTICS**: Аналитика трат (REQ-0077–REQ-0083)
- **GRP-REPORTS**: Отчеты и выписки (REQ-0084–REQ-0087)
- **GRP-API**: API и интеграции (REQ-0088–REQ-0103)
- **Дополнительные**: REQ-0104–REQ-0108 (переходы между страницами)

### Существующая схема
- **Страницы**: auth.login, home, products.overview, accounts.list, payments.transfer, deposits.open, credits.apply, analytics.spending, cards.block
- **Элементы меню**: products, payments, cards, analytics
- **Связи**: 32 связи requirement_ui_links (многие устарели — ссылаются на несуществующие REQ-*)

## Проблемы текущей схемы

1. **Устаревшие связи требований**: Многие связи ссылаются на REQ-0898, REQ-0326, REQ-0196, REQ-0878, REQ-0311, REQ-0777, REQ-0422, REQ-0831, REQ-0576, REQ-AN-001 — этих требований нет в текущем файле.

2. **Отсутствующие страницы**:
   - `cards.list` — список карт (REQ-0068)
   - `reports.statement` — выписка по счету (REQ-0084–REQ-0087)

3. **Отсутствующие связи**:
   - Связи между требованиями и существующими UI-элементами
   - Связи для API требований (REQ-0093–REQ-0103)
