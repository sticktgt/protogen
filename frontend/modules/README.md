# frontend/modules

Статические UI-файлы подключаемых модулей.

Один модуль — одна подпапка:

```text
frontend/modules/<module_id>/
```

Рекомендуемая структура:
- HTML-страницы на верхнем уровне папки модуля;
- `js/` — небольшие ES modules по функциям;
- `css/` — CSS модуля, расширяющий базовые CSS-файлы.

Состав модулей и страниц не хардкодится в JS. Страницы регистрируются в `modules/<module_id>/module.yaml`.
