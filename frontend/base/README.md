# frontend/base

Базовый UI приложения.

Содержит системные страницы:

- `login.html` — вход;
- `index.html` — стартовая страница;
- `workspace-open.html` — открытие доступного workspace;
- `workspace-create.html` — создание workspace с автоматическим ID;
- `workspaces.html` — совместимая страница со ссылками на открытие/создание;
- `settings.html` — пользовательские настройки;
- `admin.html` — минимальное системное администрирование.

Содержит общие CSS-файлы:

- `css/tokens.css`;
- `css/layout.css`;
- `css/components.css`.

Содержит общие JS helper-ы:

- `js/api.js`;
- `js/context.js`;
- `js/navigation.js`;
- `js/layout.js`;
- `js/ui.js`.
