# UI Schema

Модуль работы со схемой UI прототипа.

Модуль предназначен для хранения, просмотра и ручного редактирования логической структуры web-интерфейса будущего прототипа.

## Основные возможности

- отображение карты UI прототипа;
- отображение корневых элементов приложения, включая главное меню;
- отображение структуры выбранной страницы или корневого элемента;
- создание, переименование и удаление страниц;
- создание, переименование и удаление элементов UI;
- связь страниц и элементов UI с требованиями;
- отображение связей между UI-объектами, например `menu_item → page`, `button → page`, `button → modal`;
- отображение связей UI-объектов с файлами кода прототипа, если такие связи уже созданы.

## Данные модуля

Данные модуля хранятся в workspace в папке:

```text
ui_schema/
```

Шаблон начальных данных для нового workspace находится в:

```text
modules/ui_schema/init/
```

## Ограничения текущей версии

- модуль не генерирует UI-схему через LLM;
- модуль не генерирует код прототипа;
- переходы к требованиям и файлам кода пока не реализованы;
- файл `requirements.json` используется как демонстрационный источник требований и не редактируется этим модулем.
