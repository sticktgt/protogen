# Demo Hidden Page

Минимальный пример модуля с UI, который зарегистрирован в приложении, но не выводится в левом меню.

Назначение:
- показать параметр `menu.show: false` в `module.yaml`;
- показать переход на страницу из другого модуля через `App.navigateToPage()`;
- показать отдельный API и отдельную папку данных в workspace.
